## FontBase Highlights

- **Font Collection:** FontBase font collection browses the type you are allowed to use, arranged so a face can be found by name or by look.
- **Type Tester:** FontBase type tester sets a sentence you write into the selected face at a size you choose.
- **Project Set:** FontBase project set remembers which faces belong to one poster, paper, or small layout.
- **Font Preview:** FontBase font preview shows the face before you commit it to that project.
- **Paired Font:** FontBase paired font is the second face you keep with the first, such as a title face beside a body face.

---

## What Is FontBase

FontBase is a project-minded preview helper. FontBase font collection is the wider shelf. FontBase project set is the handful for the work in front of you. A student poster, a club page, or a short home layout stays consistent when the same two faces return every time you open the file.

FontBase type tester and FontBase font preview are how you judge a face on your own words. FontBase paired font is the discipline of choosing a partner, not a dozen unrelated display faces. You enable a set for the project, do the work, and leave the rest of the collection quiet. That suits study and small tasks better than a wall of every family at once.

Name the project after the assignment. Build FontBase project set with a title and a body choice, check both in FontBase type tester, and confirm the pair in FontBase font preview. Next class, open the same FontBase paired font instead of shopping again.

## Starting with FontBase

Prerequisites: A compatible computer, type you are allowed to use, and permission to run FontBase.

1. **Prepare:** Name the project after the poster or paper.

3. **Preview:** Use FontBase font preview on a likely title face.
4. **Test The Line:** Put the real title into FontBase type tester.
5. **Add A Partner:** Choose FontBase paired font for the body text.
6. **Save The Set:** Keep both in FontBase project set and reopen it next session.
